# 移动端适配与自动更新设计

## 目标

将已有的移动端适配脚本整理为独立项目，并通过公开 GitHub 仓库提供稳定安装地址和版本更新源。

## 结构

- `fuliba-assistant.user.js`：唯一发布产物，脚本管理器直接安装。
- `README.md`：安装、更新与维护说明。
- `TASKS.md`：里程碑、待办事项和验收标准。
- `CHANGELOG.md`：版本变更记录。
- `scripts/check-userscript.mjs`：零依赖静态检查。

## 更新链路

脚本管理器读取 `@updateURL` 中的 `@version`。发现版本号高于本地版本后，再从 `@downloadURL` 下载脚本。两个地址都指向公开仓库 `main` 分支中的同一文件，避免发布资产路径变化。

## 风险与验证

- GitHub Raw 在部分网络环境下可能不可达，需要手机网络能够访问 GitHub。
- 只有递增 `@version` 才会触发更新。
- 静态检查只验证语法、元数据和移动端样式存在；真实安装、授权、配置持久化和更新提示必须在手机脚本管理器中验收。
