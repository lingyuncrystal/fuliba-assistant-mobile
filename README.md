# 福利吧全能助手（移动端适配维护版）

这是“福利吧全能助手”的移动端配置界面适配版本，保留原脚本业务逻辑，并改善手机浏览器中的设置弹窗布局与触控体验。

## 安装

手机浏览器需要先安装支持 userscript 的扩展或脚本管理器，例如 Tampermonkey、Violentmonkey、ScriptCat、Kiwi Browser 扩展环境或其他兼容工具。

[点击安装最新版脚本](https://raw.githubusercontent.com/lingyuncrystal/fuliba-assistant-mobile/main/fuliba-assistant.user.js)

打开链接后，由脚本管理器确认安装。请保持脚本管理器中的“自动检查更新”功能开启。

## 自动更新

脚本内置以下更新地址：

- `@updateURL`：检查 GitHub `main` 分支上的版本号。
- `@downloadURL`：发现新版本后下载同一份脚本。

后续发布必须同时完成：

1. 递增脚本头部的 `@version`。
2. 更新 `CHANGELOG.md`。
3. 通过 `npm test` 检查语法与自动更新元数据。
4. 提交并推送到 `main` 分支。

脚本管理器会按照自身的检查周期发现更新，也可在脚本管理器中手动执行“检查更新”。

## 移动端适配内容

- 设置弹窗限制在手机安全区域内。
- 设置分区改为单列布局。
- 标签栏支持横向滑动。
- 内容区独立滚动。
- 输入控件与按钮采用更适合触控的尺寸。
- 小屏输入框自动占满可用宽度。
- 桌面端布局保持不变。

## 验证

```bash
npm test
```

静态检查不能替代真实浏览器验证。发布后仍应在手机脚本管理器中确认：脚本能够安装、设置面板能够完整滚动、配置可以保存，以及手动检查更新能够识别更高的 `@version`。
